# Terra dirt block

`terra_cube_roblox.glb` is the Roblox-ready copy of the supplied Earthen Relic Cube.

- Centered at the origin and scaled to 3 x 3 x 3 studs.
- 13.6 thousand triangles, within Roblox's per-mesh budget.
- The source model has no texture images, so the game tints it with a dirt-brown color.
- The Rojo project uses the imported MeshPart template at `src/shared/TerraDirtBlockTemplate.rbxmx`.

The game places these detailed soil blocks sparingly in the mine's deeper layers to keep the scene performant.
