# Terra dirt block

`terra_cube_roblox.glb` is the Roblox-ready copy of the supplied Meshy model.

- Centered at the origin and scaled to 3 x 3 x 3 studs.
- Reduced from about 5.1 million triangles to about 11.7 thousand triangles to fit Roblox's per-mesh budget.
- The source model has no texture images, so its appearance comes from the geometry and material.

Import this GLB once through Roblox Studio's 3D Importer. Rojo does not turn GLB files in this folder into MeshPart instances by itself.
